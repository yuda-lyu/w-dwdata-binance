Description:

  • 將基底週期之分段檔合併為目標週期之分段檔，各根以timeZone(固定偏移)之界線起訖，供saveData於合併時使用。 目標之分段同目標週期鍵之分段(自dayStart 00:00起每段hourInterval小時)；分段檔不存在、根數少於該段應有根數、為最新分段、或所需之基底分段檔之修改時間晚於該分段檔者重算，其餘沿用(以外部方式改動基底分段檔而未令其修改時間晚於合併分段檔者不會重算，刪除該合併分段檔即可強制重算)。 某目標根之基底各根須齊全且皆已定稿(基底所在分段檔之修改時間不早於該基底根之名目收棒加寬限)，否則不輸出該根並記入missing：reason為'open'(目標根尚未收棒加寬限)、'gap'(基底根缺漏)、'invalidBase'(基底根之數值欄無法解析)或'notFinal'(基底根擷取於其收棒前)；早於最早一根基底資料之目標根不列入(上市前)，但缺之基底根所在之分段本次請求失敗者列入(不能當成上市前；該失敗為有效觀察而已有紀錄者亦然)。

checkDataComplete(c, optopt) → {Object}

Description:

  • 判斷分段檔內容是否完整，供saveData決定是否重抓。 完整須同時滿足：有內容、末列可解析、筆數等於分段應有筆數、檔案修改時間不早於末列名目收棒時刻加寬限。 末列名目收棒時刻為末列開始時間加每筆時長，不採用檔內結束時間欄，因幣安於停機時段之歷史K線結束時間本即早於名目收棒。 檔案修改時間由saveData於寫檔後設為送出請求前之時刻，作為資料擷取時刻之保守下界；幣安於名目收棒後仍可能短暫回傳非定稿值，故須再加寬限。

(async) downloadData(endpoint, symbol, timeStart, timeEnd, interval, optopt) → {Promise}

Description:

  • 下載指定時間區間內的 K 線數據(Kline)，並可選擇轉為 CSV 格式輸出。 某根K線若於擷取當下尚未收棒，其結束時間改為擷取時刻；此僅為提示，不保證其餘各根已定稿(幣安於名目收棒後仍可能短暫回傳非定稿值)，亦非判定未收棒之充要條件(幣安停機時段之歷史K線結束時間本即早於名目收棒)。 回應若非陣列(例如HTML頁面或錯誤物件)，或其中有非陣列之列，視為無數據。 請求失敗時重試(預設3次，間隔1、3、9秒)：連線錯誤、逾時(opt.timeRequest，預設30秒)、HTTP 5xx、429(有Retry-After且不超過opt.timeRetryMax時依之)、403、HTTP 2xx而回應非陣列；HTTP 400與其餘4xx不重試，418(IP封鎖)不重試。請求成功時不多送請求、不多等待。

getIntervalPlan(interval, optopt) → {Object}

Description:

  • 依週期鍵、時區與opt.aggregateFrom決定取得方式(直接下載原生週期或由較短之原生週期合併)、存檔資料夾名與基底週期。 aggregateFrom未給(undefined或null)時為'auto'，不分週期鍵。 'none'：直接下載原生週期(各根以交易所之UTC格線起訖)。 'auto'：目標之原生格線於期間內出現之各偏移下皆與timeZone之界線對齊者直接下載(有日光節約之時區亦可，例如3m、1hr)；不對齊者取能整除目標週期且格線與timeZone之界線對齊之最大原生週期下載後合併(例如UTC+8之1day為8hr合併3根，UTC+9為1hr合併24根，UTC+5:30為30m合併48根)。 週期鍵(如'1hr')：以之為基底合併，須能整除目標週期且其格線與timeZone之界線對齊，否則拋錯；與目標週期相同且於各偏移下皆對齊時即直接下載。 須合併時timeZone須為固定偏移(期間內偏移不變)，各根之時長恆為目標週期之秒數。合併之序列存於'<週期鍵>_tz<±HHMM>_d<dayStart之YYYYMMDD>_from<基底週期鍵>'資料夾，基底存於'<基底週期鍵>_tz<±HHMM>_d'資料夾，皆不與直接下載之'<週期鍵>'資料夾共用；偏移或dayStart不同者資料夾名不同，不共用。 週期鍵、aggregateFrom(給了而無效)、timeZone無效時拋錯，訊息為'invalid <名稱>: must be <種類>'且不帶輸入值，拋錯時不連網、不建夾、不寫檔。

Description:

(2)合併：opt.aggregateFrom為'auto'(預設)或基底週期鍵，且原生格線與opt.timeZone之界線不對齊時，下載較短之原生週期(基底)後合併，各根以timeZone之界線起訖(例如台北之1day為當地00:00至24:00，由8hr合併3根；UTC+9之4hr由1hr合併4根；UTC+5:30之1hr由30m合併2根)。基底存於'<基底週期鍵>_tz<±HHMM>_d<dayStart之YYYYMMDD>'資料夾，合併之序列存於'<週期鍵>_tz<±HHMM>_d_from<基底週期鍵>'資料夾，皆不與直接下載之'<週期鍵>'資料夾共用；偏移或dayStart不同之呼叫用不同之資料夾，不會互相覆蓋或錯位(資料夾名可由getIntervalPlan預先得知，亦見回傳之aggregate.key與aggregate.baseKey)。 回傳Promise，resolve回傳物件 { timeKeep, timeLast, items }，timeLast與timeKeep為本次下載之最新分段末兩列之開始時間（乾跑或最新分段未成功下載時為undefined），items為本次下載（乾跑時為將下載）之分段陣列，各元素為 { tag, ts, te, reason }，reason為'latest'（最新分段）、'notExist'（檔案不存在）或checkDataComplete回傳之不完整原因；合併時items為基底週期之下載分段，timeLast與timeKeep為最新兩根已合併輸出之目標根之開始時間，另含aggregate物件 { key, base, baseKey, count, utcOffset, fd, segments, missing }：key為合併序列之資料夾名，base為基底週期鍵，baseKey為基底之資料夾名，count為每根由幾根基底合併，utcOffset為時區之UTC偏移分鐘數，fd為合併序列之資料夾絕對路徑，segments為本次重算之分段 [{ tag, n }]，missing為未輸出之目標根 [{ time, have, need, reason }]（reason為'open'尚未收棒、'gap'基底缺漏、'notFinal'基底擷取於收棒前、'invalidBase'基底數值無法解析；早於最早一根基底資料者不列）；reject回傳錯誤訊息 補充(回傳)：aggregate.missing之元素中，早於最早一根基底資料而缺之基底根所在之分段本次請求失敗者亦列入(不論該失敗是否為有效觀察)；reason為'gap'者，於缺之基底根有紀錄或其分段本次請求失敗時另含cause與causes：cause為缺之基底根之成因之最嚴者('unobserved'基底分段本次請求失敗而無資料 > 'unknown'尚未嘗試 > 'pending'暫無數據 > 'nodata'已標註缺根)，causes為各成因之根數 { pending, nodata, unobserved, unknown }，含暫無數據者另含validCount(最少之有效觀察次數)與firstValid(最早之首次有效觀察時刻)；缺之基底根全為'unknown'時不附(同既有)。另於非空時含：failed為本次請求失敗之分段 [{ tag, ts, te, kind, httpStatus, code, attempts, counted }]（kind為'httpError'、'badRequest'、'blocked'、'rateLimited'、'banned'、'invalidResponse'、'timeout'、'network'；attempts為實際請求次數(停止送出後之段為0)；counted為此次是否為有效觀察），gaps為期間內全部暫無數據與已標註之根 [{ tag, from, to, n, state, validCount, firstValid, lastValid, lastKind, lastHttpStatus, lastCode, uncounted, lastUncountedKind, markedAt }]（彙整期間內各段之紀錄檔，不只本次；state為'pending'或'nodata'）；items之reason另有'pending'(該段有暫無數據之根)；合併時failed與gaps為基底之請求失敗與缺根；請求皆成功且無缺根時不含failed與gaps(回傳與既有相同)。

Description:
