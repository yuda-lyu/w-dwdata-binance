/**
 * 根據指定的時間範圍與設定，自動抓取並儲存指定時長的幣種 K 線資料（Kline）。
 * 若該分段已存在資料檔，且完整，則跳過；否則會下載並儲存成 CSV 檔；最新分段每次必下載。
 * 完整之定義見checkDataComplete：有內容、末列可解析、筆數等於分段應有筆數，且檔案修改時間不早於末列名目收棒時刻加寬限(opt.timeGrace)。
 * 寫檔後會將檔案修改時間設為送出請求前之時刻，作為資料擷取時刻之保守下界；判定依賴檔案修改時間，複製資料時若未保留修改時間將無法偵測未收棒之末根，刪除該檔即可強制重抓。
 * 處理順序為最新分段優先，其餘分段由新到舊；給予opt.timeBudget時，超過之舊分段留待下次呼叫，令長時間回補期間最新分段仍能更新。
 * 週期鍵(interval)與送交易所之週期、每段時長、每段筆數：'1m'(1m, 1小時, 60筆)、'3m'(3m, 3小時, 60筆)、'5m'(5m, 4小時, 48筆)、'15m'(15m, 12小時, 48筆)、'30m'(30m, 1天, 48筆)、'1hr'(1h, 2天, 48筆)、'2hr'(2h, 4天, 48筆)、'4hr'(4h, 8天, 48筆)、'6hr'(6h, 12天, 48筆)、'8hr'(8h, 16天, 48筆)、'12hr'(12h, 24天, 48筆)、'1day'(1d, 48天, 48筆)、'1week'(1w, 48週, 48筆)；每段時長皆為每根時長之整數倍。交易所之3d(現貨與合約溢價指數之開盤對齊不同)、1M(每根長度不固定)、1s(合約不支援)不支援。
 * 取得方式(見intervals.mjs之getIntervalPlan)：交易所原生之格線以UTC為錨(1day為UTC 00:00，1week為週一UTC 00:00，日內週期為UTC epoch之整數倍)，本函數不送交易所之timeZone參數(合約端點不支援)。
 * (1)直接下載原生週期：各根以交易所之UTC格線起訖，存於'<週期鍵>'資料夾。opt.aggregateFrom為'none'、或為'auto'(預設)而原生格線於期間內之各偏移下皆與opt.timeZone之界線對齊(例如台北之1m、5m、15m、30m、1hr、2hr、4hr、8hr，UTC之1day，或任何時區之3m)時為此方式。opt.timeZone只決定時間字串之標示與分段起點，例如aggregateFrom為'none'且timeZone為'Asia/Taipei'時1day之各根標為'YYYY-MM-DDT08:00:00'。
 * (2)合併：opt.aggregateFrom為'auto'(預設)或基底週期鍵，且原生格線與opt.timeZone之界線不對齊時，下載較短之原生週期(基底)後合併，各根以timeZone之界線起訖(例如台北之1day為當地00:00至24:00，由8hr合併3根；UTC+9之4hr由1hr合併4根；UTC+5:30之1hr由30m合併2根)。基底存於'<基底週期鍵>_tz<±HHMM>_d<dayStart之YYYYMMDD>'資料夾，合併之序列存於'<週期鍵>_tz<±HHMM>_d<YYYYMMDD>_from<基底週期鍵>'資料夾，皆不與直接下載之'<週期鍵>'資料夾共用；偏移或dayStart不同之呼叫用不同之資料夾，不會互相覆蓋或錯位(資料夾名可由getIntervalPlan預先得知，亦見回傳之aggregate.key與aggregate.baseKey)。
 * 基底由週期鍵、timeZone與aggregateFrom決定，與端點無關；價格與溢價指數請以相同之aggregateFrom呼叫(或明給同一個基底週期鍵)，並可比對兩者回傳之aggregate.key是否相同以確認用了同一基底與界線。交易所於少數維護日各週期之資料不一致(實測溢價指數由8hr與由4hr合併之台北日線，2020至2026年約10日不等，多為筆數欄；價格無此現象)，故不同基底之合併結果可能不同，需與既有資料可比者請明給基底週期鍵。
 * 須合併時timeZone須於資料期間(dayStart至現在後1年)內為固定偏移，有日光節約時間或偏移變動者拋錯(請改給固定偏移，如'Etc/GMT+5'，或執行環境之Intl支援時之'-05:00')，各根之時長恆為該週期之秒數，不提供23或25小時之日；'auto'而目標之原生格線於期間內之各偏移下皆對齊者(例如有日光節約之時區之3m、1hr)為直接下載，不要求固定偏移(直接下載時，日光節約回撥之一小時內時間標示會重複，且切換日之分段沿用既有之限制)。絕對值小於30分之非零偏移不支援(時間函式庫無法正確處理)。
 * 週期鍵、opt.aggregateFrom(給了而無效)、opt.timeZone無效時拋錯，拋錯先於任何連網、建夾、寫檔，訊息依'invalid <名稱>: must be <種類>'且不帶輸入值。
 * 合併之規則：開=首根之開、高=最高、低=最低、收=末根之收，量、成交額、筆數、主動買入量與額=加總(十進位精確加總，小數位數取各根之最大者)，開始時間=首根之開始時間，結束時間=末根之結束時間。某目標根之基底各根不齊(交易所缺漏)、未收棒或擷取於收棒前者不輸出，記入回傳之aggregate.missing。合併之分段以分段檔之修改時間判定是否重算(見aggregateData)，刪除合併分段檔即可強制重算。
 * 直接下載時，分段起點不在各根之對齊格點上者(例如aggregateFrom為'none'時台北之段起點為UTC 16:00，12hr與1day之格點不在此)，每段仍為該段應有筆數，段末根之收棒晚於段終點，完整與否以末根之名目收棒判定；最新分段於其首根開盤前回應為空，此時不寫檔且timeLast與timeKeep為undefined，仍在形成之根屬前一段，由前一段之不完整判定重抓更新。
 * 抓與用分開：本函數只負責抓、重試與標註，遇缺數據時怎麼用由使用端決定。每段之請求失敗時重試(見downloadData；預設3次，間隔1、3、9秒，逾時opt.timeRequest)；418(IP封鎖)、429之Retry-After超過opt.timeRetryMax或用盡重試、403(防火牆封鎖)用盡重試、或連續opt.netFailTimes(預設3)段皆為連線層失敗(連線錯誤、逾時)時，本次執行停止送出後續請求(其餘分段列入failed，attempts為0)。
 * 暫無數據與缺根：應有之根為分段請求起訖內之UTC原生格點且已收棒加寬限者(以該次請求前之時刻計)。取不到之根(回應不含該根，或請求失敗)依該次嘗試分類：有效觀察 = HTTP 2xx陣列而缺該根，或HTTP 4xx/5xx(400、403、418、429除外)且同一K線端點於本次執行對別的分段回過2xx陣列；其餘(連線錯誤、逾時、400、403、418、429、2xx而非陣列、本次無任何2xx陣列回應之4xx/5xx)不算觀察(例：只下載單一分段而該段回錯誤、或端點路徑有誤而一律404，皆不計)。每次執行每根至多1次有效觀察。「相隔」依主機之時鐘，主機時鐘向前跳會提早標註。
 * 有效觀察累計不少於opt.noDataTimes(預設3)、且首次與最近一次相隔不少於opt.timeNoData(預設7天)時(於有效觀察之當下判定)，該根標註為缺根('nodata')，之後該段若只缺已標註之根即為完整而不再請求；未達者為暫無數據('pending')，其分段每次執行都重抓(items之reason為'pending')；任何一次取得該根即刪除其紀錄。不算觀察之嘗試不改有效觀察之次數與時刻(只累計uncounted)，故斷線期間不會被標註。
 * 紀錄存於資料夾內與分段檔同夾之'_gaps.json'(每個資料夾一個，只在該資料夾有暫無數據或已標註之根時存在；沒有時不存在，無缺根時不新增任何檔)，格式為 { v: 1, interval, timeZone, ranges: [{ tag, from, to, n, state, validCount, firstValid, lastValid, lastKind, lastHttpStatus, lastCode, uncounted, lastUncountedKind, markedAt }] }，tag為所屬分段(分段檔名)，from與to為首末根之開盤時間字串(同分段檔之時區)，firstValid、lastValid、markedAt為ISO時刻；同一分段內連續且紀錄相同之根合併為一個範圍，檔內每個範圍一列；每次執行讀一次、有變動才以寫暫存檔再改名之方式覆寫；讀取時逐範圍檢查欄位(檔案不得超過64MiB)，不合格者整檔視為無紀錄(重新累計，下次寫入時以正確內容覆蓋，無紀錄則刪除)。紀錄檔與其暫存檔不會被當成分段(分段只讀'.csv')。手動重置：刪除紀錄檔，或給opt.useResetGaps為true(本次先刪除期間內各分段之紀錄、期間外者不動；乾跑不刪)。標註後不定期重新確認。
 *
 * @async
 * @function saveData
 * @param {String} name - 資料名稱分類，例如幣種代號（如 BTC）
 * @param {String} type - 資料類型分類，例如 'spot', 'future' 等
 * @param {String} endpoint - 資料 API 端點（例如幣安的 K 線 API）
 * @param {String} symbol - 幣種交易對，例如 'BTCUSDT'
 * @param {String} interval - K 線週期鍵（如 '1m', '1hr', '4hr', '1day' 等，全部週期鍵見上），亦為存檔子資料夾名
 * @param {Object} [opt={}] - 可選設定參數
 * @param {String} [opt.dayStart='2020-01-01'] - 抓取起始時間（ISO 格式）
 * @param {String} [opt.timeZone='Asia/Taipei'] - 時間字串與 epoch 互轉所用的固定時區（IANA 時區名，如 'UTC'、'Asia/Taipei'），與下載機器本地時區脫鉤，確保跨機器產出的時間標籤一致，並透傳給 downloadData；須合併者須為無夏令時間之固定偏移時區，直接下載者於夏令時間切換日之分段會重複或缺漏；變更timeZone或dayStart時直接下載者須改用新的fdData或刪除既有檔案(合併者之資料夾名含偏移與dayStart，不共用)
 * @param {String} [opt.fdData='./data'] - 儲存的根資料夾路徑
 * @param {Object} [opt.proxy] - axios proxy 設定（如 { protocol, host, port }）
 * @param {Boolean} [opt.useConvertToCsv] - 已停用：一律以 CSV 格式儲存（舊版給予false時會導致不儲存任何檔案）
 * @param {Integer} [opt.timeGrace=60000] - 名目收棒後之寬限毫秒數，幣安於名目收棒後仍可能短暫回傳非定稿值（實測現貨約1秒、溢價指數可達15秒），擷取時刻須不早於末根名目收棒加此值才視為定稿
 * @param {Integer} [opt.timeBudget=0] - 每次呼叫處理舊分段之時間上限毫秒數，超過則剩餘舊分段留待下次呼叫，最新分段不受限，0代表不限
 * @param {Boolean} [opt.useDryRun=false] - 是否只檢查不下載，true時不發請求亦不寫檔，回傳之items列出將被下載之分段與原因
 * @param {Boolean} [opt.useShowLog=false] - 是否顯示 log 資訊
 * @param {String} [opt.aggregateFrom='auto'] - 取得方式：'auto'(對齊則直接下載，否則自動取基底合併)、'none'(直接下載原生週期)或基底週期鍵(如'1hr'，須能整除目標週期且格線與timeZone之界線對齊，否則拋錯)；undefined與null視為未給(改用'auto')，給了而無效即拋錯(決定資料口徑，不改用預設)
 * @param {Integer} [opt.retryTimes=3] - 請求失敗後之重試次數(非負整數)，0代表不重試
 * @param {Integer} [opt.timeRetry=1000] - 第i次重試前等待timeRetry*3^(i-1)毫秒(預設1、3、9秒；非負整數，上限2147483647)，每次等待不超過timeRetryMax
 * @param {Integer} [opt.timeRetryMax=60000] - 每次等待之上限毫秒數(非負整數，上限2147483647)，429之Retry-After超過此值時本次執行停止送出後續請求
 * @param {Integer} [opt.timeRequest=30000] - 單一請求之逾時毫秒數(正整數，上限2147483647，自送出至收完回應)
 * @param {Integer} [opt.netFailTimes=3] - 連續此數之分段皆為連線層失敗(連線錯誤、逾時)時停止本次執行之後續請求(非負整數)，0代表不停止
 * @param {Integer} [opt.noDataTimes=3] - 標註缺根所需之有效觀察次數(正整數)
 * @param {Integer} [opt.timeNoData=604800000] - 標註缺根所需之首次至最近一次有效觀察之相隔毫秒數(非負整數，預設7天)
 * @param {Boolean} [opt.useResetGaps=false] - 是否於本次執行先刪除期間內各分段之紀錄(手動重置)，只有true為啟用，其餘視為未給
 * 新選項之檢測(retryTimes至useResetGaps)：undefined與null視為未給(用預設)；整數類接受數字字串並轉為數值(如'3'即3)，非整數、Infinity、'0x10'為無效。noDataTimes與timeNoData決定何時永久標註為缺根、之後不再抓(錯值會使資料靜默缺漏)，給了而無效即拋錯(於任何連網、建夾、寫檔前)，訊息依'invalid opt.<名稱>: must be <種類>'且不帶輸入值；retryTimes、timeRetry、timeRetryMax、timeRequest、netFailTimes為執行參數，給了而無效改用預設(不拋)
 * @returns {Promise} 回傳Promise，resolve回傳物件 { timeKeep, timeLast, items }，timeLast與timeKeep為本次下載之最新分段末兩列之開始時間（乾跑或最新分段未成功下載時為undefined），items為本次下載（乾跑時為將下載）之分段陣列，各元素為 { tag, ts, te, reason }，reason為'latest'（最新分段）、'notExist'（檔案不存在）或checkDataComplete回傳之不完整原因；合併時items為基底週期之下載分段，timeLast與timeKeep為最新兩根已合併輸出之目標根之開始時間，另含aggregate物件 { key, base, baseKey, count, utcOffset, fd, segments, missing }：key為合併序列之資料夾名，base為基底週期鍵，baseKey為基底之資料夾名，count為每根由幾根基底合併，utcOffset為時區之UTC偏移分鐘數，fd為合併序列之資料夾絕對路徑，segments為本次重算之分段 [{ tag, n }]，missing為未輸出之目標根 [{ time, have, need, reason }]（reason為'open'尚未收棒、'gap'基底缺漏、'notFinal'基底擷取於收棒前、'invalidBase'基底數值無法解析；早於最早一根基底資料者不列）；reject回傳錯誤訊息
 * 補充(回傳)：aggregate.missing之元素中，早於最早一根基底資料而缺之基底根所在之分段本次請求失敗者亦列入(不論該失敗是否為有效觀察)；reason為'gap'者，於缺之基底根有紀錄或其分段本次請求失敗時另含cause與causes：cause為缺之基底根之成因之最嚴者('unobserved'基底分段本次請求失敗而無資料 > 'unknown'尚未嘗試 > 'pending'暫無數據 > 'nodata'已標註缺根)，causes為各成因之根數 { pending, nodata, unobserved, unknown }，含暫無數據者另含validCount(最少之有效觀察次數)與firstValid(最早之首次有效觀察時刻)；缺之基底根全為'unknown'時不附(同既有)。另於非空時含：failed為本次請求失敗之分段 [{ tag, ts, te, kind, httpStatus, code, attempts, counted }]（kind為'httpError'、'badRequest'、'blocked'、'rateLimited'、'banned'、'invalidResponse'、'timeout'、'network'；attempts為實際請求次數(停止送出後之段為0)；counted為此次是否為有效觀察），gaps為期間內全部暫無數據與已標註之根 [{ tag, from, to, n, state, validCount, firstValid, lastValid, lastKind, lastHttpStatus, lastCode, uncounted, lastUncountedKind, markedAt }]（彙整期間內各段之紀錄檔，不只本次；state為'pending'或'nodata'）；items之reason另有'pending'(該段有暫無數據之根)；合併時failed與gaps為基底之請求失敗與缺根；請求皆成功且無缺根時不含failed與gaps(回傳與既有相同)。
 */

let saveData = async(name, type, endpoint, symbol, interval, opt = {}) => {

    //check
    if (!isestr(name)) {
        throw new Error('invalid name')
    }

    //check
    if (!isestr(type)) {
        throw new Error('invalid type')
    }

    //check
    if (!isestr(endpoint)) {
        throw new Error('invalid endpoint')
    }

    //check
    if (!isestr(symbol)) {
        throw new Error('invalid symbol')
    }

    //plan, 直接下載或合併; 週期鍵、aggregateFrom、timeZone無效(含須合併而偏移有變動)時於任何連網、建夾、寫檔前拋錯
    let plan = getIntervalPlan(interval, opt)

    //check, 標註缺根之選項(noDataTimes、timeNoData)給了而無效即拋(先於任何連網、建夾、寫檔); 重試與逾時之選項(retryTimes等)給了而無效改用預設, 不拋
    getGapOpts(opt)

    //native, 直接下載原生週期, 存於以週期鍵命名之資料夾
    if (plan.mode === 'native') {
        return saveNative(name, type, endpoint, symbol, interval, opt, interval)
    }

    //base, 以同一機制下載基底週期之分段, 存於plan.baseKey之資料夾(含偏移與dayStart, 不與直接下載之同鍵資料夾共用); io.gapStore為該資料夾之紀錄(本次已讀入), 供合併判定缺根之成因而不重讀
    let io = {}
    let rb = await saveNative(name, type, endpoint, symbol, plan.base, opt, plan.baseKey, io)

    //timeZone
    let timeZone = get(opt, 'timeZone')
    if (!isestr(timeZone)) {
        timeZone = 'Asia/Taipei'
    }

    //dayStart
    let dayStart = get(opt, 'dayStart')
    if (!isday(dayStart)) {
        dayStart = '2020-01-01'
    }

    //fdData
    let fdData = get(opt, 'fdData')
    if (!isestr(fdData)) {
        fdData = './data'
    }

    //timeGrace
    let timeGrace = get(opt, 'timeGrace')
    if (!isp0int(timeGrace)) {
        timeGrace = 60 * 1000
    }
    timeGrace = cint(timeGrace)

    //useDryRun
    let useDryRun = get(opt, 'useDryRun')
    if (!isbol(useDryRun)) {
        useDryRun = false
    }

    //useShowLog
    let useShowLog = get(opt, 'useShowLog')
    if (!isbol(useShowLog)) {
        useShowLog = false
    }

    //aggregate, 合併為以timeZone之界線起訖之各根, 存於plan.key之資料夾; 乾跑時不合併
    let fd = path.resolve(fdData, name, type, plan.key)
    let r = {
        segments: [],
        missing: [],
        timeLast: undefined,
        timeKeep: undefined,
    }
    if (!useDryRun) {
        r = aggregateData({
            fdBase: path.resolve(fdData, name, type, plan.baseKey),
            fdAgg: fd,
            plan,
            timeZone,
            dayStart,
            timeGrace,
            failedBase: map(get(rb, 'failed', []), 'tag'),
            gapStore: io.gapStore,
            useShowLog,
        })
    }

    return {
        timeKeep: r.timeKeep,
        timeLast: r.timeLast,
        items: rb.items,
        ...(rb.failed ? { failed: rb.failed } : {}), //failed與gaps為基底之請求失敗與缺根, 只在非空時出現
        ...(rb.gaps ? { gaps: rb.gaps } : {}),
        aggregate: {
            key: plan.key,
            base: plan.base,
            baseKey: plan.baseKey,
            count: plan.count,
            utcOffset: plan.utcOffset,
            fd,
            segments: r.segments,
            missing: r.missing,
        },
    }
}


//saveNative, 直接下載原生週期(interval為週期表之鍵)之分段並存檔(引數已由saveData檢查); folder為存檔之資料夾名; io為內部之輸出(io.gapStore為該資料夾之紀錄)
let saveNative = async(name, type, endpoint, symbol, interval, opt, folder, io = {}) => {

    //timeZone
    let timeZone = get(opt, 'timeZone')
    if (!isestr(timeZone)) {
        timeZone = 'Asia/Taipei'
    }

    //ott
    let ott = (input) => {
        if (input === undefined || input === null) {
            return ot().tz(timeZone)
        }
        return ot.tz(input, timeZone)
    }

    //kp, 週期表(dataInterval送交易所之週期, dataSec每根秒數, hourInterval每段時數, dataNum每段筆數), 見intervals.mjs之getIntervals
    let kp = getIntervals()

    //dataInterval, 每筆時間間隔
    let dataInterval = kp[interval].dataInterval

    //dataSec, 每筆時長(秒), 供計算名目收棒時刻
    let dataSec = kp[interval].dataSec

    //dataNum, 每次抓取數據筆數
    let dataNum = kp[interval].dataNum

    //hourInterval, 每筆檔案儲存時長
    let hourInterval = kp[interval].hourInterval

    //dayStart
    let dayStart = get(opt, 'dayStart')
    if (!isday(dayStart)) {
        dayStart = '2020-01-01'
    }

    //timeStart
    let timeStart = `${dayStart}T00:00:00`

    //fdData
    let fdData = get(opt, 'fdData')
    if (!isestr(fdData)) {
        fdData = './data'
    }

    //proxy
    let proxy = get(opt, 'proxy')
    if (!iseobj(proxy)) {
        proxy = {}
    }

    //timeGrace, 名目收棒後之寬限(毫秒)
    let timeGrace = get(opt, 'timeGrace')
    if (!isp0int(timeGrace)) {
        timeGrace = 60 * 1000
    }
    timeGrace = cint(timeGrace)

    //timeBudget, 每次呼叫處理舊分段之時間上限(毫秒), 0代表不限
    let timeBudget = get(opt, 'timeBudget')
    if (!isp0int(timeBudget)) {
        timeBudget = 0
    }
    timeBudget = cint(timeBudget)

    //useDryRun
    let useDryRun = get(opt, 'useDryRun')
    if (!isbol(useDryRun)) {
        useDryRun = false
    }

    //useShowLog
    let useShowLog = get(opt, 'useShowLog')
    if (!isbol(useShowLog)) {
        useShowLog = false
    }

    //fo, go, 重試與逾時、標註缺根之選項(已由saveData檢查)
    let fo = getFetchOpts(opt)
    let go = getGapOpts(opt)

    //fd
    let fd = path.resolve(fdData, name, type, folder)
    if (!fsIsFolder(fd)) {
        fsCreateFolder(fd)
    }
    // console.log('fd', fd)

    //_timeStart
    let _timeStart = timeStart
    // console.log('_timeStart', _timeStart)

    //now
    let now = ott()

    //_timeEnd
    let _timeEnd = now.format('YYYY-MM-DDTHH:mm:ss')
    // console.log('_timeEnd', _timeEnd)

    //rts, 生成_timeStart至_timeEnd內每4小時資訊
    let rts = []
    let t = _timeStart
    let vt = ott(_timeStart, 'YYYY-MM-DDTHH:mm:ss')
    let n = -hourInterval
    while (true) {

        //n
        n += hourInterval //每hourInterval小時

        //t
        t = vt.add(n, 'hour').format('YYYY-MM-DDTHH:mm:ss')
        // console.log('t', t)

        //tag
        let tag = ott(t, 'YYYY-MM-DDTHH:mm:ss').format('YYYYMMDDHHmmss')
        // console.log('tag', tag)

        //push
        rts.push({
            tag,
            t,
        })

        //check
        if (t > _timeEnd) { //最後時間一定要超過現在時間, 使能push下一個時間點(k+1)
            break
        }

    }
    // console.log('rts', rts, size(rts))

    //gs, 本資料夾之紀錄(每資料夾一個紀錄檔'_gaps.json', 本次執行只讀一次; 無紀錄檔時不讀), 有變動才於最後寫入
    let gs = openGapStore(fd, { interval, timeZone })
    io.gapStore = gs

    //saveGaps, 寫入紀錄檔(寫檔失敗不中斷, 同分段檔)
    let saveGaps = () => {
        try {
            gs.save()
        }
        catch (err) {
            console.log(`can not save file`, fpGapsOf(fd), err)
        }
    }

    //useResetGaps, 手動重置: 先刪除期間內各分段之紀錄(乾跑不刪; 期間外之分段之紀錄不動)並寫入
    if (go.useResetGaps && !useDryRun) {
        if (gs.resetTags(new Set(map(rts.slice(0, -1), 'tag'))) > 0) {
            saveGaps()
        }
    }

    //ctx, 本次執行之狀態: reachable為同一K線端點於本次是否回過2xx陣列, halted為是否已停止送出請求(418、429、403、連續之連線層失敗)
    let ctx = { reachable: false, halted: false, haltKind: null }

    //netFails, 連續為連線層失敗(連線錯誤、逾時)之分段數
    let netFails = 0

    //att, 本次各分段之嘗試, 於全部分段處理完後才分類(可達與否須看整次執行)並更新紀錄檔
    let att = []

    //偵測既有檔案完整者不抓, 若沒檔案或不完整就下載
    let csFin = ''
    let items = []
    if (true) {

        //tRun, 本次處理起始時刻, 供timeBudget判斷
        let tRun = Date.now()

        //up
        let up = size(rts) - 1

        //k, rts最末為下一個時間點(k=up)為未來時間不須處理, 故自最新時間段(k=up-1)起往舊時間段處理, 令長時間回補期間最新時間段仍能先更新
        let k = up
        while (true) {
            k--
            if (k < 0) {
                break
            }

            //bLast, 最新時間段預設一定要下載
            let bLast = k === up - 1

            //check, 舊時間段之處理時間超過預算時留待下次呼叫, 最新時間段不受限
            if (!bLast && !useDryRun && timeBudget > 0 && Date.now() - tRun >= timeBudget) {
                break
            }

            //tag, ts
            let tag = get(rts, `${k}.tag`)
            let ts = get(rts, `${k}.t`)
            let te = get(rts, `${k + 1}.t`)
            te = ott(te, 'YYYY-MM-DDTHH:mm:ss').add(-1, 'second').format('YYYY-MM-DDTHH:mm:ss') //截止時間須-1秒, 避免抓到下個時間段之起始數據
            // console.log(`get(rts, k)`, get(rts, k))
            // console.log(`get(rts, k+1)`, get(rts, k + 1))

            //fp
            let fp = `${fd}/${tag}.csv`
            // console.log('fp', fp)

            //rangeOf, 本段請求之起訖毫秒(同downloadData之startTime與endTime); 只在需要時才換算(請求皆成功且無紀錄檔時不多做時間換算)
            let range = null
            let rangeOf = () => {
                if (range === null) {
                    range = {
                        startMs: ott(ts, 'YYYY-MM-DDTHH:mm:ss').valueOf(),
                        endMs: ott(te, 'YYYY-MM-DDTHH:mm:ss').valueOf(),
                    }
                }
                return range
            }

            //ckComplete, 確認是否完整, 回傳不完整原因, 完整時回傳空字串; num為應有筆數(已標註缺根之根不計)
            let ckComplete = (num = dataNum) => {

                let c = fs.readFileSync(fp, 'utf8')

                //mtimeMs, 寫檔後已設為送出請求前之時刻, 為資料擷取時刻之保守下界
                let mtimeMs = fs.statSync(fp).mtimeMs

                //筆數不符, 或末根擷取時刻未晚於名目收棒加寬限(例如於當前時長內中斷不下載更新, 筆數雖相同但最末數據不完全), 皆視為不完整
                let r = checkDataComplete(c, {
                    dataNum: num,
                    dataSec,
                    mtimeMs,
                    timeGrace,
                    timeZone,
                })
                if (!r.complete && useShowLog) {
                    console.log(`not complete: ${r.reason}`, fp)
                }

                return r.reason
            }

            //ckGaps, 紀錄中有該段之舊段: 有暫無數據之根則每次執行都抓('pending'); 只有已標註缺根之根時, 分段檔之各根加已標註之根等於應有之根且末根已定稿即完整, 整段皆已標註者無分段檔亦完整
            let ckGaps = () => {
                let sm = gs.summary(tag)
                if (sm.pending) {
                    if (useShowLog) {
                        console.log(`not complete: pending`, fp)
                    }
                    return 'pending'
                }
                let expected = gridOpens(rangeOf().startMs, rangeOf().endMs, interval)
                let num = size(expected) - sm.noData
                if (!fsIsFile(fp)) {
                    return num === 0 && size(expected) > 0 ? '' : 'notExist'
                }
                if (num <= 0) {
                    return 'count'
                }
                return ckComplete(num)
            }

            //reason, 須下載之原因
            let reason = ''
            if (bLast) {
                reason = 'latest' //最新時間段一定要下載
            }
            else if (gs.has(tag)) {
                reason = ckGaps() //紀錄中有該段(暫無數據或已標註缺根)
            }
            else if (!fsIsFile(fp)) {
                reason = 'notExist' //若指定時之檔案不存在就要下載
            }
            else {
                // console.log('ckComplete', fp)
                reason = ckComplete() //若指定時之檔案不完整就要下載
                // console.log('ckComplete', fp, reason)
            }
            if (reason === '') {
                continue
            }

            //push
            items.push({
                tag,
                ts,
                te,
                reason,
            })

            //check, 乾跑只檢查不下載
            if (useDryRun) {
                continue
            }

            //a, 本段之嘗試
            let a = { tag, ts, te, fp, startMs: null, endMs: null, tObs: null, kind: '', httpStatus: null, code: null, attempts: 0, opens: null }
            att.push(a)

            //check, 已停止送出請求(418、429、403, 續送會延長封鎖; 或連續之連線層失敗)時本段不請求, 記為未問到
            if (ctx.halted) {
                a.startMs = rangeOf().startMs
                a.endMs = rangeOf().endMs
                a.tObs = Date.now()
                a.kind = ctx.haltKind
                if (useShowLog) {
                    console.log(`get ${name} ${type} [${ts}] -> [${te}] skipped (${ctx.haltKind})`)
                }
                continue
            }

            if (useShowLog) {
                console.log(`get ${name} ${type} [${ts}] -> [${te}] downloading...`)
            }

            //tReq, 送出請求前之時刻, 寫檔後設為檔案修改時間
            let tReq = Date.now()
            a.tObs = tReq

            //cs, 含重試與逾時
            let d = await downloadDataDetail(endpoint, symbol, ts, te, dataInterval, {
                timeZone,
                proxy,
                useConvertToCsv: true,
                retryTimes: fo.retryTimes,
                timeRetry: fo.timeRetry,
                timeRetryMax: fo.timeRetryMax,
                timeRequest: fo.timeRequest,
                useShowLog,
            }, ctx)
            let cs = d.result
            a.kind = d.kind
            a.httpStatus = d.httpStatus
            a.code = d.code
            a.attempts = d.attempts
            a.opens = d.opens
            a.startMs = d.startTime
            a.endMs = d.endTime

            //netFails, 連續若干段皆為連線層失敗時停止本次執行之後續請求(斷線時免得每段各等重試與逾時)
            if (d.kind === 'network' || d.kind === 'timeout') {
                netFails++
                if (fo.netFailTimes > 0 && netFails >= fo.netFailTimes && !ctx.halted) {
                    ctx.halted = true
                    ctx.haltKind = d.kind
                }
            }
            else {
                netFails = 0
            }

            //check
            if (!isestr(cs)) {
                if (useShowLog) {
                    console.log(`get ${name} ${type} [${ts}] -> [${te}] no data`)
                }
                // console.log(tag, 'cs', cs)
                continue
            }

            if (useShowLog) {
                console.log(`get ${name} ${type} [${ts}] -> [${te}] finish`)
            }
            // console.log(tag, 'cs', cs)

            //save, 寫檔後將檔案修改時間設為送出請求前之時刻, 單一時間段寫檔失敗不中斷其他時間段
            try {
                fs.writeFileSync(fp, cs, 'utf8')
                fs.utimesSync(fp, new Date(), new Date(tReq))
            }
            catch (err) {
                console.log(`can not save file`, fp, err)
                continue
            }

            //update, 僅取最新時間段, 供計算timeLast與timeKeep
            if (bLast) {
                csFin = cs
            }

        }

    }

    //updateGaps, 依本段之嘗試更新各根之紀錄(只在記憶體, 全部更新完才一次寫入): 應有之根為本段請求起訖內之原生格點且已收棒加寬限(以嘗試之時刻計), 已取得者為回應與分段檔之各根; 該段無紀錄且回應不缺根時不讀分段檔、不更動紀錄
    let updateGaps = (a, counted) => {
        //不算觀察而該段無紀錄: 不新增紀錄(只累計既有紀錄之uncounted), 免讀分段檔
        if (!counted && !gs.has(a.tag)) {
            return
        }
        let expected = gridOpens(a.startMs, a.endMs, interval).filter((o) => o + dataSec * 1000 + timeGrace <= a.tObs)
        let resp = new Set(a.opens || [])
        let lack = some(expected, (o) => !resp.has(o))
        if (gs.has(a.tag) || lack) {
            let have = new Set([...resp, ...readCsvOpens(a.fp, timeZone)])
            let changed = applyAttempt(gs.barsOf(a.tag), {
                expected,
                have,
                counted,
                kind: a.kind,
                httpStatus: a.httpStatus,
                code: a.code,
                tObs: a.tObs,
            }, go)
            if (changed) {
                gs.touch(a.tag)
            }
        }
    }

    //failed, 分類與紀錄: 全部分段處理完後才分類, 錯誤回應(httpError)只在同一K線端點於本次執行對別的分段回過2xx陣列時算有效觀察
    let failed = []
    if (!useDryRun) {
        for (let a of att) {
            let counted = a.kind === 'ok' || (a.kind === 'httpError' && a.httpStatus >= 400 && ctx.reachable) //有效觀察: 2xx陣列、或4xx/5xx(400、403、418、429另分類)且同一K線端點本次回過2xx陣列; 其餘之非2xx(例: 3xx之轉址頁面)不算觀察
            if (a.kind !== 'ok') {
                failed.push({
                    tag: a.tag,
                    ts: a.ts,
                    te: a.te,
                    kind: a.kind,
                    httpStatus: a.httpStatus,
                    code: a.code,
                    attempts: a.attempts,
                    counted,
                })
            }
            updateGaps(a, counted)
        }

        //有變動(或既有紀錄檔不合格, 以本次之紀錄覆蓋, 無紀錄則刪除)才寫一次
        saveGaps()
    }

    //timeLast, timeKeep
    let timeLast = '' //最新時間 //_timeEnd
    let timeKeep = '' //最近數據不變時間 //now.add(-1, 'hour').format('YYYY-MM-DDTHH:mm:ss')
    if (true) {

        let s = sep(csFin, '\n')

        let up = size(s) - 1

        let l0 = get(s, up - 0, '')
        let l1 = get(s, up - 1, '')

        let gt = (l) => {
            let ss = sep(l, ',')
            let t = get(ss, 0)
            return t
        }

        timeLast = gt(l0)
        timeKeep = gt(l1)

    }

    //r, failed與gaps只在非空時出現(全部成功且無缺根時回傳與既有相同)
    let r = {
        timeKeep,
        timeLast,
        items,
    }
    if (size(failed) > 0) {
        r.failed = failed
    }
    let gaps = gs.list(new Set(map(rts.slice(0, -1), 'tag')))
    if (size(gaps) > 0) {
        r.gaps = gaps
    }

    return r
}
