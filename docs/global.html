checkDataComplete(c, optopt) → {Object}

Description:

  • 判斷分段檔內容是否完整，供saveData決定是否重抓。 完整須同時滿足：有內容、末列可解析、筆數等於分段應有筆數、檔案修改時間不早於末列名目收棒時刻加寬限。 末列名目收棒時刻為末列開始時間加每筆時長，不採用檔內結束時間欄，因幣安於停機時段之歷史K線結束時間本即早於名目收棒。 檔案修改時間由saveData於寫檔後設為送出請求前之時刻，作為資料擷取時刻之保守下界；幣安於名目收棒後仍可能短暫回傳非定稿值，故須再加寬限。

import checkDataComplete from './src/checkDataComplete.mjs'

let c = [
    '2026-09-30T16:00:00, 1, 2, 0.5, 1.5, 10, 2026-09-30T19:59:59, 15, 3, 5, 7',
    '2026-09-30T20:00:00, 1.5, 3, 1, 2, 12, 2026-09-30T21:30:00, 20, 4, 6, 9',
].join('\n')

//末列開始時間2026-09-30T20:00:00(台北)加4小時, 名目收棒為2026-10-01T00:00:00(台北)
let tClose = new Date('2026-10-01T00:00:00+08:00').getTime()

console.log(checkDataComplete(c, { dataNum: 2, dataSec: 14400, mtimeMs: tClose - 1000 }))
// => { complete: false, reason: 'beforeClose' }

console.log(checkDataComplete(c, { dataNum: 2, dataSec: 14400, mtimeMs: tClose + 60000 }))
// => { complete: true, reason: '' }

console.log(checkDataComplete(c, { dataNum: 48, dataSec: 14400, mtimeMs: tClose + 60000 }))
// => { complete: false, reason: 'count' }

(async) downloadData(endpoint, symbol, timeStart, timeEnd, interval, optopt) → {Promise}

Description:

  • 下載指定時間區間內的 K 線數據(Kline)，並可選擇轉為 CSV 格式輸出。 某根K線若於擷取當下尚未收棒，其結束時間改為擷取時刻；此僅為提示，不保證其餘各根已定稿(幣安於名目收棒後仍可能短暫回傳非定稿值)，亦非判定未收棒之充要條件(幣安停機時段之歷史K線結束時間本即早於名目收棒)。 回應若非陣列(例如HTML頁面或錯誤物件)，或其中有非陣列之列，視為無數據。

(async) saveData(name, type, endpoint, symbol, interval, optopt) → {Promise}

Description:

  • 根據指定的時間範圍與設定，自動抓取並儲存指定時長的幣種 K 線資料（Kline）。 若該分段已存在資料檔，且完整，則跳過；否則會下載並儲存成 CSV 檔；最新分段每次必下載。 完整之定義見checkDataComplete：有內容、末列可解析、筆數等於分段應有筆數，且檔案修改時間不早於末列名目收棒時刻加寬限(opt.timeGrace)。 寫檔後會將檔案修改時間設為送出請求前之時刻，作為資料擷取時刻之保守下界；判定依賴檔案修改時間，複製資料時若未保留修改時間將無法偵測未收棒之末根，刪除該檔即可強制重抓。 處理順序為最新分段優先，其餘分段由新到舊；給予opt.timeBudget時，超過之舊分段留待下次呼叫，令長時間回補期間最新分段仍能更新。

syncData(name, type, endpoint, symbol, optopt) → {Object|function|function}

Description:

  • 建立一個定時同步資料的任務，定期呼叫 saveData 以抓取與儲存幣種 K 線資料。 可啟動與停止，適合作為長時間後台資料同步機制。 每輪呼叫 saveData 時以同步間隔之80%作為處理舊分段之時間上限(saveData之opt.timeBudget)，最新分段每輪必抓，長時間回補期間最新分段仍能持續更新。
